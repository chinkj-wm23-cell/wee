# Valentine Flowers (纯前端)

## 怎么打开
- 直接双击 `index.html`（电脑浏览器会打开）
- 手机：把整个文件夹发过去（AirDrop/微信/Telegram/Google Drive 都行），然后在手机上打开 `index.html`

## 文件说明
- index.html 主页
- style.css 样式
- app.js 花花动画（Canvas）

## 想放到线上当“链接”
如果你要一个真正的网页链接（https://...），最简单：
1) 用 GitHub 新建一个仓库，把三个文件上传
2) 打开 Settings → Pages → 选择 Branch (main) → Save
3) 等它生成网址，把那个网址发给对方

（这套项目不需要服务器，GitHub Pages 就能跑。）
